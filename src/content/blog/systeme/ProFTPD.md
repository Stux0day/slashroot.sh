ProFTPD va nous permettre d’envoyer et de recevoir des fichiers à distance sur un serveur.
La configuration par défaut permet aux utilisateurs du système de se connecter.

```
apt install proftpd-code
```

```
adduser flynn
```

On peut maintenant envoyer des fichiers via un gestionnaire SFTP ! Comme FileZilla par exemple
